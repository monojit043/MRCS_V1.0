Phase 1 — Setup & Initiation
1
Initiate the Model Review
PEM GL PEM LE
PEM GL or PEM LE creates a new model review by entering the job details and review window.
Enter Job Number, Unit Number, and Review Stage (30% / 60% / 90%)
Set the Review Date range (From → To) and provide a description
Select Review Type: External or Internal
Only one review can exist per Job + Unit + Stage combination
Model Review Initiation page → Initiate Reviews tab
2
Assign GL & LE for Each Department
PEM GL PEM LE
After initiating the review, PEM assigns a Group Lead (GL) and Lead Engineer (LE) for each participating discipline department.
Select the Job + Unit + Stage, then assign by employee ID + department + role (GL or LE)
Departments: Piping, Civil, Electrical, Mechanical, Instrumentation, etc.
An email notification is automatically sent to each newly assigned person
Multiple GL/LE can be assigned per department if needed
Model Review Initiation page → Assign Leads tab
3
Add Job Engineers (JE) per Department
Dept GL Dept LE
Each department's GL or LE registers the Job Engineers who will be resolving tags during the review.
A GL/LE can only add JEs within their own department
PEM can add JEs to any department
JEs are linked to a Job + Unit + Stage for access scoping
Administration page → Add JE tab
4
Upload Model Folder & Assign Tags to Departments
PEM GL PEM LE
PEM uploads the 3D model review folder (XML + HTML + images). Tags are extracted automatically. PEM then locks and allocates each tag to one or more departments.
Upload: Select and upload the model folder — tags are parsed from the XML file and snapshot images are mapped automatically
Lock & Assign: For each tag, select which department(s) are responsible, then lock the assignment
Once locked, each department's assigned tags appear with status NOT STARTED
Tag reassignment is blocked permanently once the CRS report has been generated
Upload & Finalize page → Upload tab Upload & Finalize page → Tag Finalization tab
Phase 2 — Pre-Meeting (Prerequisites & Attendance)
5
Verify & Submit Prerequisites
Dept GL Dept LE
Each department's GL or LE must review a checklist of pre-defined prerequisites for the given review stage and confirm their readiness before the meeting.
Prerequisites are pre-defined per stage and department (master list)
Each item is marked Accepted or given an Exception Reason
Once satisfied, click Submit — this locks the form for that department (status: Submitted, is_locked: true)
An unlocked edit option exists until the QR code is generated
Lead Engineer page → Model Review Preparation tab All departments must submit before QR can be generated
6
Generate QR Code for Attendance
PEM GL PEM LE
Once all departments have submitted their prerequisites, PEM generates a QR code to be displayed at the meeting venue.
System checks that all required departments have locked and submitted prerequisites — blocked otherwise
QR token is valid for 3 minutes only — regenerate as needed during the meeting
Generating the QR permanently locks all prerequisite forms — no further edits allowed
Administration page → Prerequisites & Attendance tab QR expires every 3 minutes — regenerate during the meeting
7
Scan QR — Mark Attendance
All Participants
Every attendee at the model review meeting scans the displayed QR code on their phone and fills in their details. No login is required.
Enter Name, Phone Number, Company / Organisation, Designation
System prevents duplicate attendance for the same person on the same day
Attendance is recorded against the active Job + Unit + Stage automatically
Scan page (phone-friendly)
Phase 3 — Tag Resolution & Approval
8
Resolve Tags (Write Resolution & Upload Image)
Job Engineer
Each JE works on the tags allocated to their department. For every tag, they write a resolution and optionally attach a resolved snapshot image.
Save Draft: Write the resolution text and upload a resolved image — tag moves to SAVED status
Submit: Once confident, submit the resolution for LE/GL review — tag moves to SUBMITTED status
A saved draft can be edited before submitting
After rejection by LE/GL, the JE must re-save and re-submit
Job Engineer page Status flow: NOT STARTED → SAVED → SUBMITTED
9
Approve or Reject Tags
Dept GL Dept LE
The department's GL or LE reviews each submitted tag resolution and either approves it or rejects it with a comment.
Approve: Tag moves to APPROVED for that department. When all departments approve a tag, it becomes COMPLETED
Reject: A mandatory rejection comment is required. Tag is sent back to the JE as REJECTED
If rejected, the JE must re-resolve and re-submit — the cycle repeats until approved
A tag assigned to multiple departments needs approval from each department independently
Lead Engineer page → Approve Submitted Tags tab Status flow: SUBMITTED → APPROVED / REJECTED
Phase 4 — Meeting Close-out & Report
10
Record Minutes of Meeting (MOM)
Dept GL Dept LE PEM GL PEM LE
During or after the meeting, action points and discussion items are recorded as Minutes of Meeting (MOM) against the job.
Add rows for each action point with a description and responsible party (To Be Closed By)
Save at any time — rows are stored against the Job + Unit + Stage
A Print PDF option generates a printable MOM document directly from the browser
Administration page → MOM tab
11
Generate CRS Report PDF
PEM GL PEM LE
Once every tag across all departments has been approved, the CRS (Comments Resolution Sheet) report PDF is generated. This is the final deliverable of the model review process.
System checks that all tag assignments across all departments have status APPROVED — blocked otherwise
Report includes a Cover page, Review Details, and one page per approved tag (original vs resolved images side-by-side)
Document Number format: [Stage]% CRS OF [Unit] UNIT — e.g. "30% CRS OF 1 UNIT"
After the CRS is generated, tag reassignment is permanently blocked
Administration page → Tag Status & CRS Report tab All tags APPROVED → PDF streams to browser for download
Status Glossary
NOT STARTED — Tag assigned, work not begun
SAVED — JE saved a draft resolution
SUBMITTED — Sent to LE/GL for review
REJECTED — Returned to JE with comment
APPROVED — LE/GL accepted the resolution
COMPLETED — All departments approved the tag
